# Daily Notes - August 25, 2026

## Focus of the Day

- Reviewing [[RAG]] ingestion pipelines, metadata schemas, and [[LangGraph]] state graphs.

## Engineering Decisions
1. **Vector Store**: Selected **ChromaDB** because it offers zero-config embedded persistence on local storage without spinning up heavy external Docker containers.
2. **Embeddings**: Used `all-MiniLM-L6-v2` as default local embedding for fast, zero-cost development, with optional flags for OpenAI/Gemini embeddings.
3. **Agentic Router**: Decided to route queries dynamically:
   - Queries matching personal knowledge go to retrieval.
   - Generic questions (e.g. arithmetic, general programming questions) go directly to the LLM.
